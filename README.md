# Week 11B Starter - IGME-340

Our first day with the Flame game engine. We put a spaceship on screen, then move it three ways: dragging it, tapping where it should go, and an on-screen joystick.

Flame is already installed and the ship image is already in `assets/images/`. All of today's code is yours: we build `main.dart` and a new `player.dart` from scratch, following the [Week 11B notes](https://github.com/jptweb/IGME-340-Shared/blob/main/weekly/11B.md). The notes have the code for every step and a Common Issues table if you get stuck.

## Get the Code

Work in your own repo (`igme-340-week-11b-starter-<your-github-username>`), not the template. Clone it with GitHub Desktop or the command line, or edit on GitHub.com if neither one cooperates. Full steps: [Participation Repos](https://github.com/jptweb/IGME-340-Shared/blob/main/documents/participation.md).

Open the folder that *contains* `pubspec.yaml`, and don't clone into a path with spaces.

## Run It

```bash
flutter pub get
flutter run
```

Chrome or the Android emulator both work. You should see "Hello World!" in the middle of the screen. Step 3 in the notes replaces all of it.
